# =============================================================================
# ANTENNE OPENEMS — GUIDE D'INSTALLATION COMPLET POUR NOUVELLE MACHINE (WINDOWS)
# =============================================================================
#
# LE SERVEUR ET LE PARSEUR N'ONT AUCUNE DÉPENDANCE OBLIGATOIRE :
# `web_antenna.py`, `ipc2581_parser.py` et `openems_modele.py` fonctionnent avec
# la bibliothèque standard Python seule. Sur un poste sans solveur, la page s'ouvre,
# les fichiers IPC-2581 se lisent, les modèles se préparent et les scripts s'exportent.
#
# En revanche, pour LANCER les simulations électromagnétiques (FDTD), openEMS doit
# être installé comme suit (les champs .vtr s'affichent ensuite dans la page) :
#
# RACCOURCI : installé via WEB_SUITE, l'outil n'a pas besoin de ce guide. Son
# installateur (ou le bouton « Installer openEMS ») fait les étapes 2 et 3 seul ;
# il reste seulement à avoir Python 3.10 ou 3.11 64 bits sur le poste.
#
# =============================================================================
# ÉTAPE 1 : INSTALLER PYTHON 3.10 OU 3.11 (64 BITS) — IMPÉRATIF
# =============================================================================
# Pourquoi : Les roues C++ précompilées (wheels .whl) d'openEMS pour Windows ne sont
# fournies QUE pour Python 3.10 et 3.11 (cp310 et cp311).
# Avec Python 3.12 ou supérieur, l'installation échouera car aucune roue n'existe.
#
# 1. Installer Python 3.10 (ou 3.11) 64 bits (ex: depuis python.org).
# 2. À la racine du projet (dossier WEB_ANTENNA), créer et activer l'environnement :
#
#      py -3.10 -m venv env
#      .\env\Scripts\activate
#
#    (Sous Linux/macOS : python3.10 -m venv env && source env/bin/activate)
#
# =============================================================================
# ÉTAPE 2 : INSTALLER OPENEMS (SOLVEUR FDTD & GÉOMÉTRIE CSXCAD)
# =============================================================================
# Les liaisons Python et les exécutables openEMS pour Windows ne sont pas sur PyPI.
# Ils sont distribués sous forme d'archive binaire autonome.
#
# 1. Télécharger l'archive binaire Windows (64-bit) :
#    - Site officiel : https://www.openems.de/download/
#    - Ou GitHub     : https://github.com/thliebig/openEMS-project/releases
#      (Exemple d'archive : openEMS-v0.0.36-win64.zip)
#
# 2. Extraire l'archive DIRECTEMENT dans le dossier « openEMS » à la racine du projet :
#
#      WEB_ANTENNA/
#      ├── openEMS/
#      │   ├── openEMS.exe
#      │   ├── CSXCAD.dll
#      │   ├── openEMS.dll
#      │   ├── AppCSXCAD.exe
#      │   ├── python/
#      │   │   ├── CSXCAD-0.6.3-cp310-cp310-win_amd64.whl
#      │   │   ├── openEMS-0.0.36-cp310-cp310-win_amd64.whl
#      │   │   └── ...
#      │   └── ...
#      ├── web_antenna.py
#      └── requirements.txt
#
#    ATTENTION AU PIÈGE D'EXTRACTION :
#    L'outil d'extraction Windows crée souvent un sous-dossier de même nom.
#    Veillez à ne pas avoir `openEMS/openEMS/...`. Le fichier `CSXCAD.dll` et
#    le sous-dossier `python/` doivent être directement sous `openEMS/`.
#
# 3. Installer les dépendances Python avec pip :
#
#      pip install -r requirements.txt
#
#    (La directive `--find-links openEMS/python` ci-dessous indique à pip d'installer
#     les roues locales de CSXCAD et openEMS sans chercher sur PyPI).
#
#    NOTE DLL : `openems_run.py` et `web_antenna.py` injectent automatiquement
#    le chemin des DLL via `os.add_dll_directory()`. Aucune modification du PATH
#    Windows n'est nécessaire !
#
# =============================================================================
# ÉTAPE 3 : DÉMARRAGE ET VÉRIFICATION
# =============================================================================
# Lancez l'application :
#
#      python web_antenna.py
#
# (Note : si lancé avec le Python système, web_antenna.py bascule automatiquement
#  sur l'environnement virtuel `env/` s'il est présent à la racine).
#
# La console doit confirmer la détection du solveur :
#      openEMS           disponible
#
# =============================================================================
# CE QUE CHAQUE PAQUET APPORTE :
#   - numpy    : dépouillement (S11, impédance, ROE) et champ lointain (NF2FF)
#   - h5py     : lecture des champs et des données HDF5
#   - CSXCAD   : description géométrique et maillage non uniforme (roue locale)
#   - openEMS  : solveur FDTD 3D (roue locale)
# =============================================================================

# Dépendances standards hébergées sur PyPI
numpy>=1.24.0
h5py>=3.0.0

# Liaisons Python openEMS & CSXCAD (recherchées dans l'archive binaire locale)
--find-links openEMS/python
CSXCAD>=0.6.2
openEMS>=0.0.35
