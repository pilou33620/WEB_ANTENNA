# =============================================================================
# Antenne openEMS — dépendances Python
#
# LE SERVEUR ET LE PARSEUR N'EN ONT AUCUNE. `web_antenna.py`, `ipc2581_parser.py`
# et `openems_modele.py` fonctionnent avec la bibliothèque standard seule :
# sur un poste où rien de ce qui suit n'est installé, la page s'ouvre, les
# fichiers IPC-2581 se lisent, les modèles se préparent et se vérifient, et
# leurs scripts s'exportent. Seul le bouton « Lancer » est éteint.
#
# PRÉREQUIS D'INSTALLATION :
# 1. Utiliser Python 3.10 ou 3.11 (64 bits) impérativement.
# 2. Avoir extrait l'archive binaire openEMS pour Windows dans le dossier
#    « openEMS/ » à côté de web_antenna.py AVANT de lancer pip.
#
#   pip install -r requirements.txt
#
# Ce que chaque paquet apporte :
#   - numpy    : le dépouillement (S11, impédance, ROE) et le champ lointain
#   - openEMS  : les liaisons Python du solveur FDTD (roue .whl dans openEMS/python/)
#   - CSXCAD   : la description de géométrie qu'openEMS consomme (roue .whl)
#   - h5py     : la lecture des champs enregistrés par la boîte NF2FF
#
# LES ROUES WINDOWS D'OPENEMS ET CSXCAD NE SONT PAS SUR PYPI :
# Elles sont fournies dans le sous-dossier openEMS/python/ de l'archive binaire.
# La directive « --find-links openEMS/python » ci-dessous indique à pip d'y
# chercher directement les roues compatibles (cp310 / cp311).
# =============================================================================

# Dépendances standards hébergées sur PyPI

h5py>=3.0.0
