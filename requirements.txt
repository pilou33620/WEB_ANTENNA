# =============================================================================
# Antenne openEMS — dépendances Python
#
# LE SERVEUR ET LE PARSEUR N'EN ONT AUCUNE. `serveur.py`, `ipc2581_parser.py`
# et `openems_modele.py` fonctionnent avec la bibliothèque standard seule :
# sur un poste où rien de ce qui suit n'est installé, la page s'ouvre, les
# fichiers IPC-2581 se lisent, les modèles se préparent et se vérifient, et
# leurs scripts s'exportent. Seul le bouton « Lancer » est éteint.
#
#   pip install -r requirements.txt
#
# Ce que chaque paquet apporte :
#   - numpy    : le dépouillement (S11, impédance, ROE) et le champ lointain
#   - openEMS  : les liaisons Python du solveur FDTD
#   - CSXCAD   : la description de géométrie qu'openEMS consomme
#   - h5py     : la lecture des champs enregistrés par la boîte NF2FF
#
# LES BINAIRES NE SONT PAS DANS CETTE LISTE, et c'est le piège d'installation
# le plus courant : `pip install openEMS CSXCAD` pose les modules Python, pas
# les DLL. Il faut en plus l'archive binaire d'openEMS, dans un dossier
# « openEMS/ » à côté de serveur.py — `openems_run.py` y cherche CSXCAD.dll et
# l'ajoute lui-même au chemin de recherche. Sans cela, « import CSXCAD »
# échoue sur un « DLL load failed » qui ne nomme pas le fichier manquant.
# =============================================================================
